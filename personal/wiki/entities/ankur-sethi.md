# Ankur Sethi

Blogger at ankursethi.com writing about software development practices, personal projects, and the psychology of using AI coding assistants without losing comprehension of one's own code.

Key piece: [[Prevent cognitive debt by manually retyping LLM-generated code]] (2026-08-02), which argues for constraining LLM coding assistants to chat-only suggestions that the developer manually retypes, to avoid accumulating [[Cognitive Debt]].
